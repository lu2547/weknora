# OpenClaw 深度解析：开源 AI Agent 框架全景总览

## 一、OpenClaw 是什么？

OpenClaw（前身名为 Clawdbot / Moltbot）是 2026 年初爆火的开源 AI Agent 框架，短短数周 GitHub Star 突破 20 万。它代表着 AI 从"回答问题"到"执行任务"的范式转变——不再只是对话工具，而是能直接操作系统、执行实际任务的"数字员工"。

### 核心定位

```
OpenClaw = Gateway + Agents + Tools + Sessions
```

- **Gateway**：统一管理所有 Agent 和指令的网关中枢
- **Agents**：具体执行任务的 AI 智能体
- **Tools**：AI 可以调用的功能模块（技能系统）
- **Sessions**：对话上下文与状态管理

### 设计哲学

OpenClaw 基于五个核心原则：

| 原则       | 说明                                     |
| ---------- | ---------------------------------------- |
| 安全默认   | 所有功能默认采用最严格的安全配置         |
| 本地优先   | 核心功能完全在本地运行，无强制云端依赖   |
| 极简核心   | 核心网关保持轻量与稳定，扩展通过插件实现 |
| 无额外应用 | 用户可在日常通讯平台中直接使用           |
| 社区驱动   | 完全开源，由社区主导开发迭代             |

## 二、三大核心能力

OpenClaw 的核心创新在于构建了一个完整的"AI 助理操作系统"范式：

### 1. Agent Loop（智能体循环）

```
用户指令 → 理解意图 → 规划任务 → 执行工具 → 观察结果 → 循环迭代
```

采用 ReAct（Reasoning + Acting）范式，让 AI 能够处理复杂的非线性任务，最多支持 20 轮迭代。

### 2. Skills + Sandbox（技能系统 + 沙盒执行）

- **Skills**：模块化插件实现功能解耦，每个技能包含描述、参数 Schema、执行逻辑三要素
- **Sandbox**：Docker 容器隔离执行不信任代码，内存/CPU/网络受限
- 截至 2026 年 3 月，官方技能库已突破 3000 个

### 3. Memory（记忆系统）

基于本地 Markdown 文件实现长短期记忆管理：
- 工作区记忆（`MEMORY.md`）
- 每日记忆（`memory/YYYY-MM-DD.md`）
- 会话历史（`sessions.json` + `JSONL` 文件）
- 支持混合检索（向量 + 全文）


## 四、能力边界

OpenClaw 的能力取决于它能调用的工具。根据源码分析，主要工具包括：

| 类别         | 工具示例                 |
| ------------ | ------------------------ |
| 文件操作     | 读写文件、目录管理、搜索 |
| Shell执行    | 命令行操作、进程管理     |
| 浏览器自动化 | 网页浏览、截图、表单填写 |
| 通信集成     | 邮件发送、消息推送       |
| API调用      | HTTP请求、Webhook触发    |

**核心约束**：只有通过工具排列组合能够实现的事情，OpenClaw 才能做到。

## 五、与 MCP 的关系

OpenClaw **没有使用 MCP（Model Context Protocol）**，而是选择了自研的 ACP（Agent Client Protocol）：

| 对比维度 | MCP               | OpenClaw ACP       |
| -------- | ----------------- | ------------------ |
| 设计理念 | 通用协议、标准化  | 轻量、高效、可扩展 |
| 适用场景 | AI 与外部设备交互 | Agent 内部通信     |
| 性能     | 相对较重          | 更轻量             |
| 扩展性   | 需要协议升级      | 可灵活定制         |

创始人观点：MCP 是"垃圾、低效、无法规模化"——尽管有争议，但这套自研协议确实更贴合 OpenClaw 的场景。

## 六、安全风险

### 已披露漏洞

- **CVE-2026-25253**：Gateway 控制平面漏洞
- 另有 7 个 CVE：远程代码执行、命令注入、SSRF、认证绕过、路径遍历
- 独立安全审计发现 **512 个漏洞**，其中 8 个为严重级别

### 核心安全问题

1. **提示注入风险**：网页、文档、邮件中可嵌入恶意指令
2. **数据泄露风险**：恶意 Skill 可静默发送数据到外部
3. **供应链攻击**：ClawHub 中发现 341 个恶意 Skill（12%）
4. **暴露实例**：超过 21,000 个公开暴露的实例

### 安全建议

```
1. 始终使用最新版本
2. 配置 dmPolicy="pairing" 防止陌生人访问
3. 谨慎授予 Shell 执行权限
4. 定期审查 Skills 插件内容
5. 敏感场景启用操作确认机制
6. 在隔离环境中运行（独立服务器/Docker）
```

## 八、与 WeKnora 的关系

WeKnora 实现了 OpenClaw 定义的三大核心能力：

| 能力             | OpenClaw                 | WeKnora                                  |
| ---------------- | ------------------------ | ---------------------------------------- |
| Memory           | Markdown 文件 + 向量检索 | PostgreSQL + Redis + 滑动窗口 + LLM 摘要 |
| Skills + Sandbox | SKILL.md + Docker        | SKILL.md 三级加载 + Docker 沙箱          |
| Agent Loop       | ReAct 范式               | ReAct + EventBus 事件驱动                |

WeKnora 在此基础上增强了：
- 企业级知识库管理（RAG Pipeline）
- 多模型支持与负载均衡
- 更完善的权限控制体系
- MCP 协议支持（既是 Server 也是 Client）
