# 养老险GPT上线功能单页

## 可直接上PPT的文案

### 标题
养老险GPT首期上线功能

### 一句话概述
围绕养老险业务知识沉淀、共享协同与智能问答，平台已具备“知识入库 - 共享复用 - 智能推理 - 结果输出”的完整闭环，可支撑问答检索、文档比对、要素提取、文档审核等典型场景快速落地。

### 上层：通用Agent业务能力

#### 1. 基于知识库的智能问答
- 面向养老险、企业年金等业务知识，支持基于知识库内容进行自然语言问答。
- 可按选定知识库、指定文档或多文档组合进行回答，提升问答精准度与可控性。
- 支持推荐问题、分步回答与引用结果输出，便于业务人员快速获取结论。

#### 2. 文档比对
- 支持将合同文本、招投标材料、制度文件等与范本或标准版本进行对比分析。
- 可识别差异条款、关键字段变化和表述偏差，形成结构化差异说明。
- 适用于四方合同比对、制度变更核对、招采材料一致性检查等场景。

#### 3. 要素提取
- 支持从合同、报表、标书、制度文件中抽取关键业务要素。
- 可输出合同基本信息、关键条款、费用约定、期限约定、KPI指标等结构化结果。
- 适合沉淀合同要素表、招标评分要素表、业务指标摘要等标准化成果。

#### 4. 文档审核
- 支持基于知识库规则、制度口径和标准范本，对上传文档开展智能审核。
- 可辅助发现条款缺失、要素不全、口径不一致、表述异常等问题。
- 适用于合同审核、制度审核、材料完整性检查等审核类场景。

### 中层：能力增强

#### 1. 知识库能力 + 共享空间能力
- 已建设养老险/年金业务知识库，支持按业务专题分类管理，沉淀招投标材料、标化材料、监管解读、财务文件、业务数据摘要等内容。
- 支持 Excel、PDF、Word、PPT 等多格式文件上传，自动解析、摘要生成、分块入库与内容预览。
- 支持查看文档摘要、文档分块、原文片段和结构化内容，便于检索结果追溯与校验。
- 支持共享空间协作，可在团队内共享知识库和智能体，提升跨角色、跨条线复用效率。
- 支持管理员、编辑者、只读等角色分级权限，满足共享使用与权限隔离并行的管理要求。

#### 2. ReAct智能推理增强
- 支持“快速问答”与“智能推理”双模式，简单问题快速回答，复杂问题进入多步推理。
- 支持 Thinking 过程可视化，业务侧可看到模型正在分析什么、为什么这样判断。
- 支持任务规划与步骤拆解，能够先规划检索路径，再逐步调用知识检索、文档读取等能力完成复杂任务。
- 支持 Final Answer 机制，在完成多轮检索与推理后输出结构化最终答案，提升结果完整性与可读性。
- 支持多工具协同与并发调用，适合跨文档、跨主题、跨来源的综合分析任务。

#### 3. RAG检索增强
- 支持问题改写、关键词检索、语义检索相结合，提升复杂业务问题的召回效果。
- 支持 BM25 + Dense 混合检索，兼顾专业术语命中率与语义理解能力。
- 支持 Rerank 重排序、结果去重和上下文合并，提高最终答案的相关性和稳定性。
- 支持父子分块与相邻片段合并，既能精准命中细粒度内容，也能返回更完整的上下文。
- 支持引用来源和片段回溯，确保回答、比对、提取、审核结果均可追踪到知识依据。

### 底层：平台支撑
- 多格式文档解析入库：覆盖 PDF、Word、图片、Excel、Markdown、网页等内容类型。
- 检索与推理解耦：知识检索、文档解析、Agent推理、结果输出可独立扩展。
- 权限与共享隔离：知识库归属、空间共享、角色权限三层控制并行生效。
- 可持续扩展：后续可继续扩展更多知识库、更多智能体和更多业务审核规则。

## 推荐版式

### 版式结构
- 顶部 20%：标题 + 一句话概述。
- 中上 30%：4 个能力卡片，分别放“知识库问答 / 文档比对 / 要素提取 / 文档审核”。
- 中部 35%：3 列能力增强，分别放“知识库与共享空间 / ReAct增强 / RAG增强”。
- 底部 15%：放“平台支撑”横条，突出多格式解析、权限隔离、持续扩展。

### 页面表达建议
- 顶层用业务语言，强调“能做什么”。
- 中层用能力语言，强调“为什么能做成”。
- 底层用平台语言，强调“可持续上线和可扩展”。
- 整页建议用“能力分层图”而不是长段落，突出上线范围与演进空间。
